# AFF Pro Plugin

## Overview
AFF Pro is a WordPress plugin designed to help you build a sales affiliate system for WooCommerce. It provides tools and features to manage affiliates, track sales, and handle commissions efficiently.

## Features
- Affiliate management
- Sales tracking
- Commission settings
- Integration with WooCommerce
- User-friendly admin interface

## Installation
1. Upload `aff-pro.php` to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Configure the plugin settings as needed.

## Requirements
- WordPress version 3.0.1 or higher
- PHP version 5.6 or higher
